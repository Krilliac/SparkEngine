# SparkEngine Examples

> **Audience:** Programmers, designers, and artists
>
> **Thread Context:** Mixed; example-specific behavior is documented with its module
>
> **Platform/Backend Scope:** All supported platforms; example requirements vary

The maintained example catalog is split between [starter templates](Samples.md) and [game modules](getting-started/Game-Modules.md).

- Begin with [Quick-Start Tutorial](getting-started/Quick-Start-Tutorial.md) for a guided runnable example.
- Use [FPS Starter](https://github.com/Krilliac/SparkEngine/tree/Working/Templates/FPSStarter) for an FPS-oriented project.
- Use [Multiplayer Arena](https://github.com/Krilliac/SparkEngine/tree/Working/Templates/MultiplayerArena) with the [Multiplayer Quick Start](subsystems/Multiplayer-Quick-Start.md).
- Browse [`Assets/`](https://github.com/Krilliac/SparkEngine/tree/Working/Assets) for engine-side sample scenes and scripts.
- Browse [`GameModules/`](https://github.com/Krilliac/SparkEngine/tree/Working/GameModules) for complete genre-specific integration slices.

Examples track the `Working` branch and should be built with the same revision as the engine.
