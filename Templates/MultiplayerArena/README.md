# MultiplayerArena legacy template

MultiplayerArena is a bounded local arena simulation retained for compatibility outside the eight-template editor registry. It demonstrates lobby readiness, symmetric cyan-versus-magenta starts, countdown, scoring, respawn timers, and a deterministic match end without claiming a live network transport or dedicated server. Team IDs remain stable for host adapters: `1` is cyan and `2` is magenta.

The reflected `Scenes/Arena.sparkscene` uses repository-original authored cyan and magenta duelists, a center-field shield marker, modular walls, corner pylons, and colored spawn lighting. The models were generated by the deterministic Blender pipeline. `Assets/multiplayer_arena_atlas.png` supplies matching character, pickup, arena, network, and UI artwork for a host adapter. Configure the generated project against an installed SparkEngine SDK with CMake 3.25 or newer.

## Controls

With a real engine context two ready local players enter a five-second countdown, then play a bounded first-to-three match with a 90-second limit. Cyan uses `WASD` and attacks with `F`; magenta uses `IJKL` and attacks with `O`. Attacks score only when the opposing player is within three world units. Eliminated players respawn after three seconds. Press `R` to reset scores, symmetric spawn positions, readiness, and the countdown.

## Live playtest checkpoints

1. Cyan and magenta begin at opposite six-unit spawn points under their matching lights, facing the center marker.
2. Neither player moves during the five-second countdown. After it ends, both stay inside the nine-unit arena clamp.
3. An attack outside three units does nothing; an in-range attack scores once and hides the eliminated duelist for three seconds.
4. First to three ends the match. If the 90-second clock expires tied, the phase enters overtime; otherwise the leader wins. `R` returns to the ready lobby loop.

The wall and corner-pylon meshes are visual composition guides. Movement remains a transport-neutral kinematic sample without collision resolution, so projects should add authoritative physics before using those meshes as blockers.

All source and repository-original artwork are covered by the SparkEngine repository license. No third-party content is bundled.

## Runtime asset sheet

`Assets/multiplayer_arena_runtime_sheet.png` is the normalized 3x3 sprite sheet used by the runtime HUD. `Assets/runtime_sheet.json` gives nine stable, named 418x418 source rectangles with transparent gutters. The larger atlas remains concept and reference art; other sheet consumers should use the descriptor rather than guessing coordinates.
