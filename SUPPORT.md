# Support Policy

SparkEngine has no published stable release or paid support offering. The
`stable-v1` profile is blocked and uncertified, so it is not a supported release
line. The `Working` branch is a development channel and receives best-effort
community support.

## Supported Versions

| Release line | Status |
|---|---|
| `stable-v1` | Pre-release and blocked; no supported version has been published |
| `Working` | Development channel only; fixes are best-effort and do not constitute a release SLA |

## Where to ask for help

- Use [GitHub Issues](https://github.com/Krilliac/SparkEngine/issues) for
  reproducible bugs, build failures, and documentation corrections.
- Include the operating system, compiler, CMake preset, commit, and the exact
  command and output needed to reproduce the problem.
- Security vulnerabilities must use the private reporting channel in
  [SECURITY.md](SECURITY.md), never a public issue.

Versioned support requires reviewed publication evidence and a certified release
profile. A source tag alone does not establish either condition.
